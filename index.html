Operating layer

What every venture runs on.

The reason a studio can run several companies at once is that most of the work is the same work. These four functions are built once and shared across the group.

Analytics and attribution

Spend, revenue, CAC and repeat rate in one view, assembled from platform ad exports, GA4 and Search Console. Judged on contribution, not on platform-reported ROAS.

Creative production

Short-form video and static creative produced in batches, each cut carrying a hypothesis about the hook, the offer or the audience.

Paid media

Meta, TikTok and YouTube campaigns built around creative testing. Budget moves toward the cuts that sell, reviewed weekly.

Automation engineering

The pipelines that do the repetitive work: data collection, reporting assembly, scoring and distribution — built to run unattended.

Built on Claude

The group's internal tooling runs on the Claude API.

Marketing work is analysis-heavy and document-heavy, which is exactly the shape of problem the Claude API handles well. Four places it carries the load:

What we run on it

  • Agentic pipelines that take an export and return a finished analysis without a person in the loop
  • Long-context processing of large structured exports — search console dumps, ad exports, analytics pulls
  • Creative generation and scoring at batch scale, ranked before anything is produced
  • Client reporting assembled from the same pipeline that produced the numbers

What we need from it

  • Higher throughput tiers for parallel batch analysis across several client accounts at once
  • Long-context and tool-use guidance for very large structured exports
  • Zero-retention terms with a DPA — client data cannot be used to train anything
